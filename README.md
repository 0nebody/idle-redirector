# idle_redirector

[![Github Actions Status](https://github.com/0nebody/idle-redirector/workflows/Build/badge.svg)](https://github.com/0nebody/idle-redirector/actions/workflows/build.yml)

A JupyterLab extension to redirect idle JupyterHub users to the JupyterHub server home.

## Requirements

- JupyterLab >= 4.0.0

## Install

To install the extension, execute:

```bash
pip install idle_redirector
```

## Uninstall

To remove the extension, execute:

```bash
pip uninstall idle_redirector
```
